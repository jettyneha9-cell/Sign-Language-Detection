# Sign-Language-Detection
It's a full end to end DETR object detection pipeline, in this video its fine tuned for detecting signs but it could definitely be repurposed for other object detection tasks. It covers:  ⚡️ Detections using my pre-trained transformer 💾 Collecting custom data for you to train your own 🏋🏽‍♀️ Fine tuning, with or without pre-trained weights
